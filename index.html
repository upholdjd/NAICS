NAICS Static REST API v1 LIVE

A free, static JSON API for 2,404 NAICS classification codes, served via GitHub Pages.

All endpoints return JSON. No authentication required. CORS is enabled by default on GitHub Pages. Source data and build scripts are on GitHub.

NAICS codes are strings, not numbers. Some codes have leading zeros (e.g., "09"). Always treat them as strings.

Base URL

https://upholdjd.github.io/NAICS/api/v1/

Endpoints

All Codes

EndpointDescription
codes.json All 2,404 codes (summary: code, name, level, sector)
codes-full.json All 2,404 codes (full records with descriptions)
stats.json Dataset statistics (counts by level and by sector)
search-index.json Compact index for client-side search (keys: c, n, s)

Individual Code Lookup

EndpointDescription
naics/{code}.json Single code with full record, children, and breadcrumb ancestry
children/{code}.json Direct children of a code (non-leaf codes only)

Browse by Level

EndpointDescription
level/sector.json All 29 sectors
level/subsector.json All 124 subsectors
level/industry-group.json All 376 industry groups
level/industry.json All 773 industries
level/us-industry.json All 1,102 US industries

Browse by Sector

EndpointDescription
sector/{code}.json All codes belonging to a sector (29 sectors available)
sector/{code}/tree.json Hierarchical tree for one sector
tree.json Full hierarchical tree (all sectors)

Mini Records

EndpointDescription
mini/codes.json All 2,404 NAICS_Mini records
mini/{code}.json Individual mini record

Response Format

Every endpoint returns a consistent envelope:

{
  "meta": {
    "version": "1.0.0",
    "generated": "2026-02-18T00:00:00.000Z",
    "source": "https://github.com/upholdjd/NAICS",
    "endpoint": "/naics/51.json"
  },
  "data": { ... }
}

Data Schema (Full Record)

FieldTypeDescription
naicsstringNAICS code (leading zeros preserved)
levelstringSector, Subsector, Industry Group, Industry, or US Industry
sector_namestringSector display name
formal_namestringOfficial name of the classification
descriptionstringDescription of the classification
parentstring | nullParent code (null for sectors)
sectorstringSector code this belongs to

Enriched Fields (naics/{code}.json only)

FieldTypeDescription
breadcrumbarrayAncestry chain from root sector to parent
childrenarrayDirect children (code, name, level)

Try It

Usage Example

const BASE = 'https://upholdjd.github.io/NAICS/api/v1';

// Fetch a single code
const res = await fetch(`${BASE}/naics/517311.json`);
const { data } = await res.json();

console.log(data.formal_name);  // "Wired Telecommunications Carriers"
console.log(data.breadcrumb);   // ancestry chain
console.log(data.children);     // direct children

Notes

  • Data is generated from static JSON files and rebuilt on each push to main.
  • No server, no database, no API keys. Just static JSON on GitHub Pages.
  • CORS is enabled by default, so you can fetch() from any origin.
  • If you need the raw source data, see the repository.
